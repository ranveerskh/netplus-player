NETPLUS IPTV PLAYER — WINDOWS EXE BUILD

1. Extract this ZIP on your computer.
2. Open https://github.com/ranveerskh/netplus-iptv-player
3. Click Add file > Upload files.
4. Drag every extracted file and folder into the upload area, then click Commit changes.
5. Open the Actions tab. The “Build Windows installer” job starts automatically.
6. When it has a green check mark, open that job and download the artifact named
   Netplus-IPTV-Player-Setup.

The downloaded artifact contains the unsigned Windows installer:
Netplus-IPTV-Player-Setup-0.1.0.exe

Customers do not need Node.js. This first test installer is unsigned, so Windows
may show a security warning until a Netplus code-signing certificate is added.
